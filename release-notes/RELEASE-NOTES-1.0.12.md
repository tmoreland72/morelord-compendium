# Graypes Compendium 1.0.12

## What Changed

### Added

- Adventures is a new, empty Adventure compendium pack (type Adventure, D&D5e system) in the Graypes Compendium folder. Players have no access; assistants own it. Foundry creates its database the first time the module loads.

## Compatibility and verification

Foundry 13 remains the supported minimum, and the verified version stays 14.368. Foundry 14.369 is the latest stable release but was not tested for this release. The manifest parses, the Adventures pack declaration was checked, and the release-synchronizer tests and changelog check passed. No in-Foundry check was run for this release.
