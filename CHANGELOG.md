# Graypes Compendium Changelog

## 1.0.15

- Added five faction actors from Dev to the Actors compendium: Silver Order, Amethyst Academy, Queen's Men, Followers of the Falling Fire, and Hooded Lanterns.

- Added seven playlists and their sound records from Dev.
- Added eleven campsite scenes and synchronized updates to 48 existing scenes and their level records.

### Compatibility

Foundry 13 remains the minimum and 14.368 remains the verified build. All 14 compendium packs were compared offline against the previous release.

## 1.0.14

- Added seven items from the Dev Items pack, including four quest items and three Sceptre of Saint Vitruvio variants.

### Compatibility

Foundry 13 remains the minimum and 14.368 remains the verified build. The Items pack was checked offline against the previous release.

## 1.0.13

- Updated scenes and other compendium packs.
- Included the Adventures pack database.
- Added 510 Drakkenheim token images.

### Compatibility

Foundry 13 remains the minimum. The verified build remains 14.368. No live Foundry verification was performed for this release.

## 1.0.12

### Added

- Adventures is a new, empty Adventure compendium pack (type Adventure, D&D5e system) in the Graypes Compendium folder. Players have no access; assistants own it. Foundry creates its database the first time the module loads.

## 1.0.11

### Added

- Adjust volume of all songs is a GM-only macro that sets every saved playlist-track volume to 25% by default. Its percent constant accepts finite values from 0 to 100 and uses Foundry's native audio volume curve.

### Improvements

- Added the manifest changelog link and consolidated release history in release-notes/.
- Temporary working files belong in ignored /tmp/; temporary files and release-note sources are excluded from GitHub installation archives.

## 1.0.10

- Rename the visible module and compendium folder to Graypes Compendium, separate from Morelord Gaming tools. Preserve internal package, pack, and document identifiers.
- Add seven personal playlists with 98 sound entries, preserving the Morelord Gaming / Drakkenheim grouping and the six existing playlists. Audio file references are preserved; audio files are not newly bundled.
- Verify the live content and folder organization in Dev1 on Foundry 14.368 / D&D5e 6.0.3. Foundry 13 remains the supported minimum.

Distributed through the existing GitHub manifest only; no Foundry package-directory or website publication.
